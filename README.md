# Каталог книг на Yii2

Небольшое web-приложение на Yii2, PHP 8+ и MySQL/MariaDB. Это публичный пример решения тестового задания, а не шаблон для промышленного сервиса.

## Исходное тестовое задание

Требовался каталог книг и авторов на Yii2 + MySQL. Книга содержит название, год, описание, ISBN и фото главной страницы и может иметь нескольких авторов. Гость просматривает каталог и подписывается по номеру телефона на **конкретного автора**. Авторизованный пользователь просматривает и выполняет CRUD книг и авторов. Публичная страница показывает ТОП-10 авторов по числу книг за выбранный год. Дополнительный пункт задания — SMS гостю о новой книге подписанного автора через [SMSPilot](https://smspilot.ru/apikey.php); для проверки допускается ключ эмулятора. API, PDF-отчёт, администрирование подписок и отписка не требовались.

## Реализованные сценарии

- Регистрация и вход пользователя; чтение книг, авторов и отчёта доступно всем.
- Создание, изменение и удаление книг и авторов доступны после входа. Книга сохраняется со всеми выбранными авторами.
- Гость оформляет подписку на странице автора. Повторная подписка того же номера на того же автора отклоняется.
- При создании книги подписчики её авторов получают уведомление. Один номер получает одно SMS, даже если подписан на нескольких авторов книги.
- Обложки хранятся в локальном MinIO через S3-совместимый адаптер. ТОП-10 считается запросом к БД.

## Запуск

Нужны Docker и Docker Compose. Скопируйте пример переменных окружения; в `.env` задайте локальные значения. Этот файл исключён из Git.

```bash
cp .env.example .env
docker compose up -d --build
docker compose exec app php yii migrate --interactive=0
```

Откройте [http://localhost:8080](http://localhost:8080). MinIO доступен на `http://localhost:9001` (локальные демонстрационные учётные данные — в `.env.example`). Не используйте эти значения для публичного развёртывания. В `docker-compose.yml` поднимаются PHP-FPM, Nginx, MySQL и MinIO; `vendor`, `runtime` и `web/assets` не входят в репозиторий.

## Проверка SMS в режиме эмуляции

По умолчанию `.env.example` содержит [публичный ключ эмулятора SMSPilot](https://smspilot.ru/apikey.php) и `SMSPILOT_TEST=1`. Реальной отправки при проверке быть не должно. Запустите приложение, создайте автора, откройте его страницу без входа и подпишитесь с тестовым номером. Затем войдите и создайте книгу с этим автором. Сбой SMSPilot записывается как обезличенное предупреждение в `runtime/logs/app.log`, уже сохранённая книга остаётся в каталоге. Код проверяет HTTP-статус, JSON, ответ `error` и подтверждение отправки в `send[0]`. Сообщение от сервиса и номер телефона не попадают в журнал. Для боевого ключа используйте только локальную переменную окружения `SMSPILOT_API_KEY`; не помещайте его в Git.

## Проверки

```bash
composer install
git ls-files '*.php' | xargs -n1 php -l
php tests/run.php
```

Сценарные проверки используют SQLite в памяти и уже установленный Yii2, поэтому отдельная тестовая БД не нужна. Они покрывают права гостя, связи книги с авторами и отчёт, повторную подписку, дедупликацию SMS, ошибки ответа SMSPilot и жизненный цикл обложек. Эти же команды выполняются в GitHub Actions. Для ручной проверки полного стека запустите Docker Compose и миграцию по инструкции выше.

## Последующие улучшения и решения

Исходный вариант уже использовал уникальный индекс для пары «автор + номер», дедупликацию получателей и предварительную загрузку авторов книг. При доработке добавлены компенсационное удаление новой обложки после неудачного сохранения, очистка старой обложки после замены или удаления книги, постраничные списки по 20 записей и проверка ответа SMSPilot. Связи книг на странице загружаются отдельным запросом после ограничения страницы, чтобы не создавать запрос на каждого автора.

Уведомление отправляется после фиксации книги в БД. Очереди и повторной отправки нет: при недоступности SMSPilot сообщение может не дойти, а книга остаётся сохранённой. Очистка MinIO после фиксации БД выполняется по возможности; при недоступности хранилища предупреждение не отменяет операцию с книгой и объект может потребовать ручной очистки. Такое ограничение оставлено в рамках малого тестового приложения.
